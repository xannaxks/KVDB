Detailed Description

Concrete LSM-tree implementation of the KVDB interface.

Engine owns the WAL, mutable/immutable MemTables, manifest, level metadata, SSTable manager, and compaction scheduler. Public operations are serialized by an internal mutex so that WAL ordering, sequence assignment, and metadata publication remain consistent.

The write path is WAL -> MemTable -> optional flush/compaction. The read path checks the MemTable generations first, then searches candidate SSTables from newest to oldest.
