Detailed Description

Red-black tree containing versioned InternalRecord values.

Nodes are ordered first by user key and then by descending sequence number, allowing the first match for a key to represent its newest version. Standard red-black rotations and recoloring keep lookup and insertion logarithmic.

Note
Nodes reference ArenaEntry storage but do not own those bytes.
