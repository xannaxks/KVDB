Detailed Description

Merges selected SSTables into replacement tables.

A job verifies that the plan still matches the supplied level snapshot, opens one iterator per input, performs a k-way merge, drops superseded versions according to compaction policy, and builds output SSTables. It returns a VersionEdit describing the files to add and delete; publishing that edit remains the Engine/Manifest's responsibility.
