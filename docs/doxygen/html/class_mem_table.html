Detailed Description

Thread-safe owner of the active RBTree and its immutable generations.

New records enter the mutable tree. Freezing atomically moves that tree to an ordered immutable queue and installs a fresh mutable tree. Readers inspect all generations, while flush code holds a shared snapshot until the exact generation is durably published and retired.

Note
The ArenaEntry storage referenced by records is externally owned and must outlive every generation that can still be read.
