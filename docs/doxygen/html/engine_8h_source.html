28/**
29 * @brief Concrete LSM-tree implementation of the KVDB interface.
30 *
31 * Engine owns the WAL, mutable/immutable MemTables, manifest, level metadata,
32 * SSTable manager, and compaction scheduler. Public operations are serialized
33 * by an internal mutex so that WAL ordering, sequence assignment, and metadata
34 * publication remain consistent.
35 *

37 * checks the MemTable generations first, then searches candidate SSTables from
