\doxysubsection{Detailed Description}
Append-\/only version log for durable database metadata. 

The manifest records \doxylink{struct_version_edit}{Version\+Edit} entries rather than rewriting the complete level state. Recovery replays the valid prefix transactionally into a \doxylink{class_level_manager}{Level\+Manager}. A torn final edit is recoverable; corruption within the durable prefix is reported as an error.
