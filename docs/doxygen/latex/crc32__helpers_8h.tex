\doxysubsection{Detailed Description}
CRC32 accumulation over canonical on-\/disk encodings. 

Integer helpers always hash little-\/endian bytes, making checksums independent of host endianness. Callers initialize a running state with init\+\_\+crc\+\_\+buff() and append fields in their serialized order.
