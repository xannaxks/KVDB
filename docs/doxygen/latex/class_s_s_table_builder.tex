\doxysubsection{Detailed Description}
Converts an immutable record source into a publishable \doxylink{class_s_s_table}{SSTable}. 

The overloads normalize \doxylink{class_mem_table}{Mem\+Table}, iterator, and vector inputs into the same ordered build path. An empty source returns an empty optional instead of creating a file.
