\doxysubsection{Detailed Description}
Groups non-\/owning record payloads into checksummed physical blocks. 

Blocks never split a record and are aligned to \doxylink{class_s_s_table}{SSTable} block boundaries. Writing a block simultaneously contributes its key range and offset to the \doxylink{struct_s_s_table_entities_1_1_index_section}{Index\+Section}.
