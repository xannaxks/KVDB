\doxysubsection{Detailed Description}
Append-\/only writer for a single active \doxylink{class_w_a_l}{WAL} generation. 

\doxylink{class_w_a_l_writer_ac3cd5afee6c3dcb2b48d9c6547d42cb8}{create()} writes a fresh file header. \doxylink{class_w_a_l_writer_a67b7a05a5ce840d91fd2b8687c0e9f9d}{write()} encodes an \doxylink{struct_internal_record}{Internal\+Record} and fragments it across physical blocks as needed. rotate() closes the current generation before creating the next one.
