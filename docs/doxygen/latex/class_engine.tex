\doxysubsection{Detailed Description}
Concrete LSM-\/tree implementation of the \doxylink{class_k_v_d_b}{KVDB} interface. 

\doxylink{class_engine}{Engine} owns the \doxylink{class_w_a_l}{WAL}, mutable/\+immutable Mem\+Tables, manifest, level metadata, \doxylink{class_s_s_table}{SSTable} manager, and compaction scheduler. Public operations are serialized by an internal mutex so that \doxylink{class_w_a_l}{WAL} ordering, sequence assignment, and metadata publication remain consistent.

The write path is \doxylink{class_w_a_l}{WAL} -\/\texorpdfstring{$>$}{>} \doxylink{class_mem_table}{Mem\+Table} -\/\texorpdfstring{$>$}{>} optional flush/\+compaction. The read path checks the \doxylink{class_mem_table}{Mem\+Table} generations first, then searches candidate SSTables from newest to oldest.
