\doxysubsection{Detailed Description}
Abstract interface for writeable files. 

Defines the operations that platform-\/specific implementations, such as Windows and POSIX writable files, must provide.

Implementations must override operations including:\+

\begin{DoxyWarning}{Warning}

\end{DoxyWarning}
\begin{DoxyNote}{Note}
The rename operation does not by itself guarantee that the directory metadata has reached persistent storage.

On POSIX systems, ::\+rename() provides atomic namespace replacement when its platform and filesystem requirements are satisfied. However, a successful return does not by itself make the rename durable across a system crash.

On Windows, Move\+File\+Ex\+W() does not provide a general guarantee that the replacement is crash-\/atomic or durable on every filesystem and storage configuration.
\end{DoxyNote}
On POSIX systems, durable replacement normally requires synchronizing the newly written file before renaming it and synchronizing the affected parent directory after the rename. If the source and destination have different parent directories, both directories may need to be synchronized.

On Windows, MOVEFILE\+\_\+\+WRITE\+\_\+\+THROUGH requests that Move\+File\+Ex\+W() wait until the move operation is completed.
