\doxysubsection{Detailed Description}
State-\/checked aggregate of all sections in one \doxylink{class_s_s_table}{SSTable} file. 

Records are globally ordered by user key ascending and sequence descending. Lookup first consults the Bloom filter, narrows the search with the index, validates candidate data blocks, and materializes the newest matching record into the caller\textquotesingle{}s \doxylink{class_arena}{Arena}.
