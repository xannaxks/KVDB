\doxysubsection{Detailed Description}
Write-\/ahead logging, fragmentation, and crash recovery. 

The write-\/ahead log (\doxylink{class_w_a_l}{WAL}) records database mutations before they are applied to the in-\/memory \doxylink{class_mem_table}{Mem\+Table}. If the process terminates before the \doxylink{class_mem_table}{Mem\+Table} is flushed to an \doxylink{class_s_s_table}{SSTable}, the \doxylink{class_w_a_l}{WAL} can be replayed during database recovery to reconstruct the lost in-\/memory state.

\doxylink{class_w_a_l}{WAL} records are appended sequentially. A logical record may be stored as one or more fragments when it does not fit within a single \doxylink{class_w_a_l}{WAL} block.

Each fragment header contains metadata required to validate and reconstruct the corresponding logical record, such as the fragment type, payload size, and checksum.

A mutation is considered recoverable only after its \doxylink{class_w_a_l}{WAL} record has been written and synchronized according to the configured durability policy.
