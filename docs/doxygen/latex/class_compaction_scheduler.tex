\doxysubsection{Detailed Description}
Stateless policy object that turns level pressure into a plan. 

The scheduler prioritizes L0 pressure, then scans higher compactable levels. It expands a chosen source range with every overlapping table in the destination level so the resulting plan preserves non-\/overlap invariants.
