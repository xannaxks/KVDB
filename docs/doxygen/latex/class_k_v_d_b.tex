\doxysubsection{Detailed Description}
Abstract, thread-\/safe interface to the LSM key-\/value database. 

Mutations are ordered through the write-\/ahead log and \doxylink{class_mem_table}{Mem\+Table}. Reads search the in-\/memory generations before consulting SSTables. Use \doxylink{class_k_v_d_b_a41747ed9695c687bbcb962f0e1da7da6}{open()} instead of constructing an implementation directly.
