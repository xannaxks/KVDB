\doxysubsection{Detailed Description}
Header-\/only map of data blocks with on-\/demand CRC validation. 

Loading discovers block boundaries without materializing payload bytes. Individual blocks are validated and decoded only when lookup or iteration needs them, keeping the normal open path small.
