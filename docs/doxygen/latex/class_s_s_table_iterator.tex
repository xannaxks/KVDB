\doxysubsection{Detailed Description}
Lazily reads \doxylink{class_s_s_table}{SSTable} data blocks in internal-\/key order. 

Only the current block\textquotesingle{}s records are materialized. Their key/\+value bytes are copied into the supplied \doxylink{class_arena}{Arena} and therefore follow its lifetime.
