\doxysubsection{Detailed Description}
Coordinates \doxylink{class_s_s_table}{SSTable} file lifecycle within one database directory. 

The manager assigns canonical temporary/\+final paths, delegates building and loading, and caches loaded tables by id so readers can share immutable structural metadata.

\begin{DoxyNote}{Note}
Cache access is not currently synchronized. 
\end{DoxyNote}
