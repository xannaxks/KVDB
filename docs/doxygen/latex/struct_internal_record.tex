\doxysubsection{Detailed Description}
Non-\/owning versioned record stored in Mem\+Tables, WALs, and SSTables. 

Sequence numbers establish recency for equal user keys. Tombstone records carry deletion state through lookup and compaction. Key and value bytes are referenced through \doxylink{struct_arena_entry}{Arena\+Entry} and therefore inherit the arena\textquotesingle{}s lifetime.
