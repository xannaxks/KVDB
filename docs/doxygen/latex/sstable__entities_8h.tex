Shared constants and section types for \doxylink{class_s_s_table}{SSTable} format version 1. 

The physical layout is:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{file\ header\ |\ aligned\ data\ blocks\ |\ index\ |\ bloom\ |\ metadata\ |\ file\ footer}

\end{DoxyCode}


Offsets and sizes in the footer provide bounded random access to the variable sections; each section also carries its own validation metadata.
