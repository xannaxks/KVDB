\doxysubsection{Detailed Description}
Complete input selection and output policy for a compaction job. 

Source tables and overlapping target-\/level tables form a single sorted merge. The smallest/\+largest keys describe the selected user-\/key interval and the output size controls when the job rolls to another \doxylink{class_s_s_table}{SSTable}.
