\doxysubsection{Detailed Description}
Provides classes, types and utilities for error handling. 

Instead of terminating execution when an operation fails, these entities allow functions to return objects containing an appropriate error code and descriptive message. This enables callers to handle failures explicitly.

\begin{DoxyNote}{Note}
These entities are not currently thread-\/safe. 
\end{DoxyNote}
