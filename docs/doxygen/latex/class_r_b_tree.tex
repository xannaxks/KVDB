\doxysubsection{Detailed Description}
Red-\/black tree containing versioned \doxylink{struct_internal_record}{Internal\+Record} values. 

Nodes are ordered first by user key and then by descending sequence number, allowing the first match for a key to represent its newest version. Standard red-\/black rotations and recoloring keep lookup and insertion logarithmic.

\begin{DoxyNote}{Note}
Nodes reference \doxylink{struct_arena_entry}{Arena\+Entry} storage but do not own those bytes. 
\end{DoxyNote}
