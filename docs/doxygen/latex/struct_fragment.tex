\doxysubsection{Detailed Description}
One physical piece of a logical \doxylink{class_w_a_l}{WAL} mutation record. 

Large records are divided into FIRST/\+\+MIDDLE/\+\+LAST fragments at block boundaries. Small records use FULL. The checksum covers both the fragment header fields and payload.
