\doxysubsection{Detailed Description}
Checksummed mapping from inclusive key ranges to data blocks. 

Adjacent entries may share a boundary key when versions of one user key span blocks. Candidate lookup therefore returns a range, while ordinary newest-\/value lookup selects its earliest entry.
