\doxysubsection{Detailed Description}
Immutable sorted-\/table aggregate, lookup path, and file lifecycle. 

An \doxylink{class_s_s_table}{SSTable} is built at a temporary path, serialized section by section, made durable, and atomically renamed to its final path. Loaded tables retain only section metadata and read record bytes lazily through Data\+Section\+View.
